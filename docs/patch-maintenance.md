# Patch maintenance and provenance

The fixed Chrome 156 patch remains [`patches/metal-family1-v1/runtime.patch`](../patches/metal-family1-v1/runtime.patch), SHA-256 `dedac2c57daa69b72fe78bbde443f45d5a6cdfe128d4022049a35c0dbbf501b0`. Its ID, bytes, five ordered source paths, source blob IDs, Chrome 156 binding, and recipe digest are preserved. Its `candidate_for_new_angle` selector is now false; the known 156 resolver still selects it by its fixed binding.

Chrome 158 has an independent candidate patchset, [`patches/metal-family1-158-v1/runtime.patch`](../patches/metal-family1-158-v1/runtime.patch), SHA-256 `5a3956dbc6428cc6afe610b09a99d4eeaadedb6b8ac396e8e6ccd670a2983def`. [`catalog/chrome/158.0.8127.37.json`](../catalog/chrome/158.0.8127.37.json) is explicitly `candidate_only`; it records the Chromium and ANGLE pins but has no fixed baseline binding. The patchset source blob IDs are for ANGLE `1f6526a566c27c7c33aa73a78517450a4a2a1714`, and its apply order lists the five patch paths. The separate recipe `macos-x64-metal-158-v1` is the new candidate default. The 156 binding continues to select `metal-family1-v1` and `macos-x64-metal-v1` regardless of these selector changes.

The 158 patchset and recipe are the unregistered-version defaults because the previous candidate failed on 158's upstream API removals. This lets the explicit retry select a patch that matches the exact 158 source structure. The recipe keeps the existing x86_64 runner, Xcode/SDK, deployment target, GN settings, and Ninja targets because the failure occurred before GN and provided no evidence for changing build settings. The recipe remains a separate source mapping and its digest is `99966e8b1bdc647db9be1bf356716ecb0719aa03e151658ffd98e67aea67339a`. These defaults also affect future unregistered Chrome/ANGLE inputs until reviewed defaults change; they are candidate selections, not compatibility certification.

The 158 source removed `injectAsmStatementIntoLoopBodies` and `generateShareableShaders`. The 158 patch does not restore them; it adds only the new default-false `emulateUnpackSnorm4x8` option to the current Metal options structure and initializes the translator member that uses it. Since the upstream `ANGLE_SH_VERSION` is 426 and this patch changes the shader translation API, the patch increments it to 427. The 156 patch bytes and its historical API version remain untouched.

Chrome 156 is bound to recipe `macos-x64-metal-v1` and its build-recipe digest. That digest is the SHA-256 of canonical JSON with only the `candidate_default` selector removed. Changing which recipe is the default for unregistered versions therefore does not invalidate or replace the baseline. The 156 reproduction workflow still checks the exact bound IDs and hashes. To test an alternate recipe or patchset for a known version, supply both IDs explicitly; the result is classified as a trial, not as baseline reproduction.

For Chrome Stable 156.0.8078.48, Chromium commit `d0c02bfad08ec92a6ffcf989e53cd995e6381a4c` pins ANGLE `3b89d84e9d59f75675ac4e2bef58fc068a9f0577`. The changes narrowly add an explicit native Mac Family 1 opt-in, preserve the ordinary and Family 2 path, use a legacy Metal math-option fallback only for the opted-in case, and emit a scalar vertex-stage `unpackSnorm4x8` helper for that path. Existing ANGLE source copyright and license notices remain in upstream source.

The patch sources are recorded against the public ANGLE repository at their exact revisions. The build verifies the mapped source blobs whenever the resolved revision equals the patchset source revision; otherwise, candidate compatibility is checked by exact `git apply --check`, diff/path checks, and all focused policy tests. Those checks do not prove compilation or runtime compatibility. Automation never edits a patch.

The project license is scoped in the [README](../README.md) to repository-authored workflow files, scripts, and documentation. It does not make a blanket rights statement for every current file or replace a third-party license. The upstream ANGLE license is kept at [`licenses/ANGLE-LICENSE.txt`](../licenses/ANGLE-LICENSE.txt) and applies to upstream ANGLE material under its terms. The artifact includes upstream license and notice files from the checked-out source. Chrome, KOOV, and unrelated third-party materials remain outside that scope.
